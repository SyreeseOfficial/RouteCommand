## Security and abuse (PROMOTE these out of "Later": real company data and a public URL)
- [ ] **[H] PROMOTE** Whole repo is published. `netlify.toml` has no `publish` dir, so `Code.gs`, `CreditCode.gs`, `DonationCode.gs`, `PRD.md`, `PROMPTS.md`, `data.json` etc. are downloadable from the live site. `Code.gs:13-14` contains the Drive folder ID and Sheet ID; `data.json` has employee full names and customer store names. One fix covers it: build into `dist/` (copy only `index.html`, `app.js`, `style.css`, `sw.js`, `data.json`, icons) and set `publish = "dist"`.
- [ ] **[H]** Securing only the Netlify function is not enough: the GAS web app URL is hardcoded in `netlify/functions/submit-*.mjs`, so it is also public in the repo, and the deployment is "Anyone". Anyone can POST straight to Google and fill your Drive folder or Sheet. Put a shared secret in Netlify env **and** in GAS `PropertiesService`; the function adds it to the body, `doPost` rejects when missing/wrong. Rotate the GAS deployment URL afterwards (new deployment = new URL) and move it to a Netlify env var.
- [ ] **[H] PROMOTE** The passcode is a constant compared in the browser (`app.js:72-73`), visible to anyone who opens DevTools or the repo. Move the check into a Netlify function (`/api/auth`) that compares against an env var and returns a signed token (HMAC, 30-day expiry); the submit functions require that token. Combine with per-person PINs (from "cheap features") to also fix "anyone can submit as anyone".
- [ ] **[M]** No size/shape validation in `doPost` (`Code.gs:56-70`): `imageData` has no max length (a 50 MB base64 string will eat the daily Apps Script quota or time out), `amount` and `receiptDate` are not validated, `category` is free text. Reject images over ~2 MB decoded, require `^\d{4}-\d{2}-\d{2}$` dates, amount `> 0` and `< 10000`, and `category` in an allowlist.
- [ ] **[M]** `savedFile.setSharing(ANYONE_WITH_LINK)` (`Code.gs:90`) makes every receipt photo (names, card last-4, addresses) public to anyone with the link. If accounting sits in the same Workspace domain use `DOMAIN_WITH_LINK`, or skip per-file sharing and let the folder's permissions apply.
- [ ] **[M]** Sheet formula injection (`= + - @`) is parked but trivial: prefix with `'` in `sanitize()` (`Code.gs:163`), same in the other two `.gs` files.
- [ ] **[L]** Build command runs `npx -y esbuild` unpinned and **overwrites `app.js`/`style.css` in place** (`netlify.toml:3`). Running it locally destroys your source files, and a new esbuild release can change the output unexpectedly. Add `esbuild` as a pinned devDependency and output to `dist/`.
- [ ] **[L]** No rate limiting or logging on the functions. Netlify's `context.ip` + a small in-memory counter, and `console.log` of failures, gives you something to look at when a submission "went missing".
